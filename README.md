# Fist Racer — Road Trip Edition

Браузерная аркадная гонка с клавиатурным, жестовым и голосовым управлением.

## Запуск через GitHub Pages

Загрузи файлы из этого архива **в корень** репозитория. В настройках репозитория выбери **Settings → Pages → Deploy from a branch → main → /(root)**. После успешной сборки игра откроется по ссылке GitHub Pages.

Клавиатура: `←` / `→` или `A` / `D` — поворот, `↑` / `W` — газ, `Space` / `↓` — тормоз, `Enter` — старт, `Esc` — пауза.

Для управления камерой сайт должен открываться по HTTPS; браузер запросит разрешение на камеру. Модель распознавания загружается с MediaPipe CDN, поэтому для этого режима нужен интернет. Голосовое управление зависит от поддержки Web Speech API браузером и тоже может требовать интернет.

## Что есть в игре

- Шесть сменяющихся локаций: ночной город, пустынный каньон, сосновый лес, снежные горы, побережье и неоновый мегаполис. Порядок локаций меняется в каждой новой гонке.
- Извилистая трасса с плавными поворотами и S-образными участками.
- Трафик из трёх полос. При создании машин проверяется дистанция, а автомобили в одной полосе не проезжают друг сквозь друга.
- Бонусы: звезда даёт 100 очков, ускорение добавляет скорость, щит временно защищает от столкновения.

## Файлы

- `index.html` — интерфейс и стили.
- `app.js` — графика, ввод и игровой цикл.
- `core.mjs` — логика гонки, локаций, трафика и бонусов.
- `audio.mjs`, `voice.mjs` — звук и распознавание команд.
- `cars.mjs` — дополнительные векторные спрайты автомобилей.

Для публикации достаточно файлов в корне архива. Устанавливать Python или библиотеки не нужно.
