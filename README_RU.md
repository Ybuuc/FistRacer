# Fist Racer

Браузерная аркадная гонка с управлением клавиатурой, жестами и голосом.

## Опубликовать на GitHub Pages

1. Загрузите все файлы из архива прямо в корень GitHub-репозитория.
2. В репозитории откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните настройки.
4. Откройте опубликованную ссылку. Камера работает только по HTTPS или на `localhost`.

## Управление

- Клавиатура: `←` / `→` или `A` / `D` — руль; `↑` / `W` — газ; `Space` / `↓` — тормоз; `Enter` — старт; `Esc` — пауза.
- Камера: кулак — газ и руль; открытая ладонь — тормоз; знак ✌️, удерживаемый около секунды, — старт или продолжение.
- Голос: короткие команды «старт», «пауза», «газ», «тормоз», «быстрее», «медленнее», «скорость 240» или «рука». Если браузер выдаёт промежуточный результат, команда выполняется после короткой проверки устойчивости, не дожидаясь финала распознавания. Сам сервис распознавания остаётся зависимым от браузера и может требовать интернет.

Справа можно настроить чувствительность руля и максимальную скорость от 120 до 240 км/ч. Игра запоминает выбранный предел в браузере. По умолчанию установлено 240 км/ч.

## Бонусы и биомы

- Шесть локаций сменяют друг друга с плавным смешиванием цветов трассы, неба и декораций.
- Звезда добавляет 100 очков.
- Бонус ускорения сразу добавляет скорость и на несколько секунд ускоряет автомобиль, вплоть до заданного лимита.
- Щит на шесть секунд блокирует столкновения; оставшееся время показано значком 🛡️ на игровом экране.

## Требования и файлы

Для клавиатурного режима установка не нужна. Управление камерой использует MediaPipe, загружаемый из CDN, а голос — Web Speech API браузера. Нужны HTTPS и интернет для загрузки модели и для браузеров, отправляющих речь в онлайн-сервис.

- `index.html` — интерфейс и оформление.
- `app.js` — графика, камера, ввод и игровой цикл.
- `core.mjs` — логика гонки, биомов, бонусов и столкновений.
- `voice.mjs` — голосовые команды и тест микрофона.
- `audio.mjs` — синтезированный звук.
- `cars.mjs` — векторные спрайты автомобилей.
- `.nojekyll` — служебный файл GitHub Pages.
